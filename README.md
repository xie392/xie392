# Hi there 👋 I'm Xie

热爱折腾的前端开发者，喜欢把各种想法做成真正能用的小工具。  
平时主要写 `TypeScript / Vue / React`，也在持续探索 `Go`、`Rust`、`Tauri` 和后端工程化。

对我来说，编程不只是工作，更像是一种长期兴趣。  
比起重复造页面，我更喜欢研究：

- ⚡ 工程化与开发体验
- 🧩 Chrome 扩展与效率工具
- 🖥️ 桌面应用与跨端开发
- 🚀 性能优化与架构设计
- 🔧 能真正解决问题的小产品

目前正在朝着独立开发者的方向前进。  
希望未来可以靠自己喜欢的产品和项目生活。

> Code what you love. Build what you enjoy.
